### ContraCovid v2 by Jennifer Bautista

This contact tracing app project that was generated with [Angular CLI](https://github.com/angular/angular-cli) version 9.1.12 initially.
Demo deployed on https://contra-covid2-git-master-jlusong15s-projects.vercel.app/

### Updates
- Year 2020: Design and development are done (so design my seem outdated)
- Year 2020: This project was only Angular version 9
- Year 2026: This project is now upgrade to Angular version 20

### Run the Application on Dev Server

The simplest way to start the application is to:
```
npm install
```

then

```
ng serve
```

Then navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.
